<h1>Wilds SS14</h1



This is a fork of Space Station 14 Persistence, which is a fork of Space Station 14. Wilds SS14<sub><i>working title</i></sub> attempts to not use NT lore and do something a different in a fresh, hardcore survival setting in a near-future era where all actions, stations, ships and (most) events are fully built and player-driven, craft everything previously unavailable, interact with new and rebalanced mechanics intended specifically for longer rounds, new recipes and devices, create factions with custom assignments and accesses, and more. Extended daily rounds that save everything at the end, and resume next next day.
